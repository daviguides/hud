## Unicode Character Database

The tables in `crates/hud-width/src/tables.rs` are generated by `cargo xtask gen-width` from
these files of the Unicode Character Database, version 17.0.0, kept unmodified in
`xtask/data/ucd-17.0.0/` with their SHA-256 checksums in `SHA256SUMS`:

`EastAsianWidth.txt`, `GraphemeBreakProperty.txt`, `DerivedGeneralCategory.txt`,
`DerivedCoreProperties.txt`, `emoji-data.txt`, `emoji-variation-sequences.txt` and, for the
conformance test only, `GraphemeBreakTest.txt`.

## Python Rich

hud is an independent implementation and contains no Rich code. Rich 15.0.0 (MIT, Copyright
(c) 2020 Will McGugan) is used as a measuring instrument: the files under `bench/golden/` are
the bytes it produced for inputs written in this project. Its name and version are recorded in
`bench/golden/manifest.json`.
