# Changelog

All notable changes to `hud` and `hud-width` are listed here. The two crates are released together; the rules for what a version may change are in [STABILITY.md](STABILITY.md).

## 1.0.0

First stable release of `hud` and `hud-width`.

### hud-width

- Terminal cell width and grapheme-cluster segmentation (UAX #29, Unicode 17): `cell_width`, `cell_width_of_cluster`, `char_width`, `clusters`, `fold`, `truncate` and `pad` cut only between clusters. `no_std`, no dependencies. Tables generated by `cargo xtask gen-width` from pinned Unicode Character Database files under the Unicode License v3.

### hud

- **Styled text.** `Style` (`"bold red on #223344"`), markup (`[bold]ok[/]`), `Text` with spans, `Console` with wrapping, justification, tabs and overflow, in the colors the terminal has (truecolor, 256, 16 or none; `NO_COLOR` removes color and keeps bold). One resolver decides what a stream can show (`NO_COLOR`, `FORCE_COLOR`, `CLICOLOR`, `CLICOLOR_FORCE`, `COLORTERM`, `TERM`, pipes, size, Windows consoles).
- **Widgets.** `Table`, `Panel`, `Tree`, `Padding`, `Group`, `Columns`, `Layout`, `ErrorReport`, `Progress` (bar, percentage, count, elapsed, remaining and spinner columns), `Live`, `Status` and `Spinner` (73 animations).
- **Three formats from one call.** Rich (styled text), plain (no escape sequence) and JSON (the document `hud/1`, valid under `crates/hud/schema/hud-1.json`), chosen with `ConsoleBuilder::format` or `HUD_FORMAT`.
- **Byte for byte Rich.** The styled output matches Python Rich 15.0.0 for the corpus in `bench/` (five corpora, 1 000 cases and more, and thousands of random vectors); the deviations are listed in `DEVIATIONS.md`.
- **Measured.** Correctness 100% on every corpus, width agreement 99.2% against Rich with 0 grapheme splits, capability matrix 40 of 40, S1 first byte 0.070 times Python Rich and S2 to S4 at 0.23, 0.18 and 0.30 times the best existing Rust crate; the 11 canonical tasks written first try by fresh agents holding only the docs (Sonnet 5.5: 55 of 55 and 54 of 55 in two runs). Details in `bench/EVALUATION-RESULTS.md`.
- **API freeze.** `#[non_exhaustive]` on `ColorSystem`, `Format`, `BoxStyle`, `Attribute`, `ProgressColumn`, `Capabilities`, `EnvSnapshot` and `StreamInfo`; `EnvSnapshot` and `StreamInfo` have constructors and setters. `Renderable` is open: implement `render`, the other methods have defaults.

MSRV 1.85. No Cargo features.
