# hud-width

Terminal cell width and grapheme-cluster segmentation for Rust. `no_std`, no dependencies.

```rust
use hud_width::{cell_width, clusters, fold, truncate};

assert_eq!(cell_width("你好🇧🇷"), 6);
assert_eq!(clusters("e\u{301}x").count(), 2);
assert_eq!(truncate("你好世界", 5), "你好");
assert_eq!(fold("ab你cd", 3).collect::<Vec<_>>(), ["ab", "你c", "d"]);
```

- **Clusters, not code points.** Segmentation follows UAX #29 (Unicode 17) including emoji
  ZWJ sequences, regional-indicator flags, Hangul syllables and Indic conjuncts (rule GB9c).
- **Never split a cluster.** `fold`, `truncate` and `pad` cut only between clusters, so
  the property holds by construction.
- **Generated tables.** The lookup tables are generated by `cargo xtask gen-width` from
  pinned Unicode Character Database files, used under the Unicode License v3 (see
  `THIRD_PARTY_NOTICES.md` in the repository).
