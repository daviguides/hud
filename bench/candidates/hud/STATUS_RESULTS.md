## What the instruments were checked for before the numbers were trusted

- **A perfect first run is suspicious, so it was attacked.** The 182 goldens were compared a second way (`cmp` on the files, not the harness), 6 of them are empty by design, the ASCII oracle vectors are all distinct (1 100 of 1 100 for `spinner`) so the comparison is not collapsing onto one output, and the properties and the oracle were run with the library deliberately broken: no space after the frame, a frame index off by one and a speed that never takes effect each make all four oracle tests fail; the three fuzz mutations above are caught.
- **The clock is part of the case.** The reference renders with an injected clock (`Console(get_time=...)`) and the refresh thread of `Status` switched off, so a frame is drawn only by an explicit event; hud's side uses `Status::refresh` and a shared clock. The floating point rule is the same arithmetic in the same order (`((time - start) * speed) / (interval / 1000) + offset`, truncation, modulo), and the corpus includes the cases where Python itself truncates 0.9999999999999787 to frame 0.
- **Rich's `update` quirk is reproduced on purpose.** `Status.update` passes the speed to the spinner on every call, so an update with no new speed still resets the base of the animation (offset and start move to the current frame); hud does the same and the oracle covers it.
- **A harness defect found on the way** (changelog 59, 60): the first `cargo fmt` reformatted the generated spinner table, so the generator now marks it `#[rustfmt::skip]`; and `tests/test_dx_runner.py` still expected the 8-task suite and had been failing on main since v0.8, so it now expects 11 tasks. Neither touches a threshold, a golden or a runner behavior.
- **Process note.** While running the mutation checks a backup of one file overwrote another with the same name; it was caught by the build failing, the file was rewritten from its reviewed text, and every check below was run again on the restored tree (unit tests, oracle, doctests, fuzz and the comparison against the goldens).

## Not claimed (D-054 to D-059)

Spinner text is markup, not any renderable; an unknown name gives `dots`; the default style is a typed green `Style`, not a theme key; in JSON a spinner is the text of its message; measuring a spinner fixes the start of its animation as Rich does (not covered by the corpus); the animations are data extracted from Rich with the notices of both licenses.
